# Нічний Київ | Монітор

Android-додаток для моніторингу ігрового сервера **CS 1.6** за протоколом A2S_INFO.

## Можливості

- UDP-запит A2S_INFO до сервера (за замовчуванням `91.211.118.84:27035`)
- Foreground Service — моніторинг не зупиняється системою
- Сповіщення при переході Онлайн ↔ Офлайн (звук + вібрація)
- Анти-спам: 3 спроби перед зміною статусу на «Офлайн»
- Автозапуск після перезавантаження телефону
- Налаштування IP, порту, інтервалу та кількості спроб
- Лог останніх 50 подій
- Повністю український інтерфейс (Jetpack Compose + Material 3)

## Вимоги

- Android 10+ (API 29)
- Дозвіл на сповіщення (Android 13+)

## Збірка

GitHub Actions автоматично збирає Debug APK при кожному пуші в `main` і створює Release.
